## Command E1: the H-87 evidence run (synthetic, deterministic, writes nothing)

E1 is a single Python process with these steps:
1. Force the process time zone to UTC+9 (`TZ=JST-9`, then `time.tzset()`). A local-time default would then differ from the UTC wall clock by 9 hours.
2. Count DeprecationWarnings through a `warnings.showwarning` hook.
3. Build the 10 models with defaults through the domain API, using the same synthetic constructor arguments as the lead's test.
4. Pass a Specification with one DoneWhenCriterion, Assumption and Unknown through the real persistence mapper `SpecificationMapper.to_model`. This builds the ORM object in memory, with no database.
5. Print the shape of each value, never the value itself, so the output is identical from run to run.

What failure looks like:
- A timezone-aware default prints `offset_free=False`, or raises TypeError when it is compared with a naive time (non-zero exit).
- A local-time naive default prints `utc_wall_clock=False`. The planner's negative control, a factory returning `datetime.now()`, printed False for every field.
- A deprecated factory left in place shows up in a non-zero `deprecation_warnings` count.
