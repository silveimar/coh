## Command P (path extraction; the same regex for every file)

```
grep -n -o -E '[A-Za-z0-9_.~{}<>-]*/[A-Za-z0-9_./~{}<>-]*|[A-Za-z0-9_-]+\.(md|py|toml|ini|yaml|yml|json|lock|db|mako|cfg|txt)|\.(coveragerc|python-version|gitignore)' <worktree>/<file>
```

It prints `line:token` for every slash-bearing token, every filename with a listed extension and the three dotfiles. Count the tokens of a file with the same grep piped to `wc -l`. For `docs/coding-rules.md`, keep only the tokens whose line number lies between the `## Repository Structure` heading and the line before `## Project Status`; take both bounds from `grep -n '^## ' <worktree>/docs/coding-rules.md`.

Put every token in exactly one class:
- R, a repository path. Resolve it to a path from the repository root. Tree entries resolve through their parents in the tree, against the tree's root line (`.`, `src/execution_core/` relative to the README's package, `apps/api/src/coh_api/`). A relative link target such as `../../docs/x.md` resolves against the README's directory. A bare filename resolves to the directory that its sentence or list names: the persistence Architecture list means `packages/persistence/src/persistence/infrastructure/`, and the archive Testing list means `tests/packages/archive/`. The link text and the link target of one link are two R tokens with one resolved path.
- P, planned: the token's line contains the word `planned`.
- X, not a repository path. Name the reason: runtime path (`.coh/...`, created by the adapters, never committed); URL or HTTP route; placeholder (`/path/to/...`, `{session_id}`, a filename pattern such as `-part-N.md`); host path outside the repository; convention (`src/`); or slash-joined prose words (`login/logout`, `HTTP/SSE`). X tokens of one file can share a single row that lists them with their line numbers.

Check existence with ONE `ls -d` per file. Its arguments are every resolved R and P path of that file as `<worktree>/<path>`, without a trailing slash. A printed path means it exists; `ls: cannot access ... No such file or directory` means it is missing. Paste stdout and stderr into 05-EVIDENCE.md with the worktree prefix written as `<worktree>`. This is the `test -e` result that criterion 6 asks for.
